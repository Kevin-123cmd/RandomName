# 随机中文姓名生成器 (RandomName)

一个**零依赖**的中文姓名随机生成小工具。提供两个版本，数据完全一致，可完全离线使用：

- **命令行版**：`src/RandomName.py`（纯Python标准库）
- **网页版**：`web/index.html`（单HTML文件，双击即用）

---

## 主要功能

- 内置500个常见中文姓氏+1934个常用汉字
- 随机生成2~3字姓名，格式统一为「姓+1~2个随机字」
- 无需联网、无需安装任何第三方包
- 网页版额外支持：一键复制姓名、分享链接、深色/浅色主题切换

## 命令行版

需要本地已安装 Python 3（任意 3.x 版本均可）。

```bash
python src/RandomName.py
```

运行示例：

```
请输入要生成的名字数量：10
邱宁紧
汪该
侯故
夹谷币座
羊腹
解帽浅
姚净惭
雍仪们
徐臭探
幸淋
...
```

> 小提示：每个名字 = 随机姓氏 + 1~2 个常用汉字随机组合，结果为纯随机字符串，无常用字加权，无男女名常用字分池，不限男女，不保证符合真实姓名语义习惯。

## 网页版

无需安装，直接用浏览器打开 `web/index.html` 即可使用。

- 在「生成数量」里输入数字（0–500），点击 **生成姓名**
- 点击单条姓名可单独复制；**复制全部** 可一键复制所有结果
- **复制分享链接** 可分享链接给好友，让他们也体验一下
- 可根据自身偏好，点击右上角按钮切换 **深色 / 浅色** 主题

## 部署网页版（可选）

网页版是纯静态单文件，可一键托管到 GitHub Pages：

1. 在仓库 **Settings → Pages** 中，Source 选择 `main` 分支、`/ (root)` 目录，保存
2. 稍等片刻，访问 `https://<你的用户名>.github.io/RandomName/web/` 即可在线使用
